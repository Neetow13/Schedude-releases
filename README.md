# Schedude — downloads

APKs oficiais do Schedude para Android 8.0 ou superior.

Baixe a versão mais recente em [Releases](https://github.com/Neetow13/Schedude-releases/releases/latest). Instale sobre a versão anterior, sem desinstalar, para manter seus dados.

A partir da versão 3.14, o próprio aplicativo permite verificar e baixar atualizações no menu **Atualizações**. O Android pode pedir autorização para instalar.

Este repositório contém apenas a distribuição pública do aplicativo. O código-fonte permanece em um repositório privado. Nenhuma conta do GitHub é necessária para baixar o APK.

The official Schedude APK is available under Releases. Install over the previous version to keep your data. Source code is maintained privately.

El APK oficial de Schedude está disponible en Releases. Instala sobre la versión anterior para conservar tus datos. El código fuente se mantiene privado.
